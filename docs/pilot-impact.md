# Pilot Usage and Early User Feedback

## Project

**Quran Halaqat Management** is an open-source desktop application designed to help Quran teachers organize study circles (halaqat), student records, attendance, memorization, revision, and periodic reports.

Repository: https://github.com/Wesambot/Quran-Halaqat-Management  
License: MIT

## Early pilot usage

The following figures are maintainer-reported and have not been independently audited:

- **Teachers:** The maintainer reports that seven fellow teachers, in addition to the maintainer, have used the application.
- **Students reached:** The maintainer estimates that the study circles managed with the application serve approximately 100 students.
- **Reported use:** Teachers have used the application in their actual halaqa workflow, including attendance tracking, memorization and revision records, and report preparation.

These are early pilot figures, not independently verified adoption or download statistics. Students are beneficiaries of the managed study circles; they are not counted as software users.

## Intended next steps

The project aims to improve the reliability and usability of digital administration for Quran study circles. Planned maintenance priorities include:

- Expand automated tests for core calculations, reporting, and data handling.
- Fix issues reported by teachers and improve the clarity of Arabic user-facing workflows.
- Improve setup instructions and contributor documentation so other educators and developers can evaluate, install, and contribute to the project.
- Continue validating the application in real teaching workflows and collect consent-based, privacy-preserving feedback.

## Evidence and limitations

This document records information reported by the maintainer as of 25 November 2026. The teacher and student figures have not been independently verified. The short comments above were shared informally; they should not be interpreted as representative survey results. The project does not publish student names, contact details, attendance records, or other personally identifying student data in this impact note.
