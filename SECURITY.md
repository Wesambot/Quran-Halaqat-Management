# Security and privacy

- Never commit real student, parent, teacher, attendance, memorization, or contact records.
- Never commit local SQLite databases, backups, logs, exported reports, credentials, API keys, or private configuration.
- Use synthetic data in screenshots, examples, and tests.
- Report suspected vulnerabilities privately to the repository maintainer; do not publish personal data or exploit details in public issues.
- Before each release, inspect the staged Git diff and run a secret scan.
