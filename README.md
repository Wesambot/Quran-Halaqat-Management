# نظام إدارة الحلقات القرآنية

تطبيق مكتبي باللغة العربية لإدارة حلقات تحفيظ القرآن الكريم، مبني باستخدام Python وFlet وقاعدة بيانات SQLite.

> **حالة المشروع:** نسخة مرشحة للإعداد كمشروع مفتوح المصدر. لم تُنشر للعامة بعد.

## المزايا

- إدارة بيانات المعلم والحلقات والطلاب.
- تسجيل الحضور: حاضر، غائب، متأخر، ومستأذن.
- تسجيل الحفظ والمراجعة من سورة وآية إلى سورة وآية.
- تسجيل عدد الصفحات يدوياً عند التسميع.
- تقارير يومية وأسبوعية وشهرية وسنوية وفق الوظائف الموجودة في التطبيق.
- تصدير التقارير إلى PDF بعد إعداد الخط العربي.
- ملفات الطلاب والإنجازات والإعدادات والإحصائيات.

> هذه قائمة بالوظائف الموجودة في النسخة الحالية، وليست ضماناً بأن كل وظيفة اجتازت اختبارات آلية.

## المتطلبات

- Python 3.12 (موصى به)
- Flet 0.24.1
- fpdf2
- arabic-reshaper
- python-bidi

## التثبيت والتشغيل

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate

python -m pip install -r requirements.txt
python main.py
```

## إعداد خط PDF العربي

يتطلب تصدير PDF وجود الملفين التاليين داخل `assets/fonts/`:

- `Amiri-Regular.ttf`
- `Amiri-Bold.ttf`

ملفات الخط غير مضمنة في المستودع. اتبع تعليمات `assets/fonts/README_AR.txt` لتنزيلها من مصدرها، واحتفظ بإشعار الترخيص عند إعادة توزيعها.

## بيانات القرآن الكريم

يحتوي `utils/quran_data.py` على بيانات وصفية للسور وعدد الآيات وصفحات مصحف المدينة وبدايات الأجزاء والأحزاب. ويحتوي `utils/hizb_boundaries.py` على نقاط بداية الأحزاب الستين. تشير تعليقات المصدر داخل الملفات إلى مجمع الملك فهد، مع الإشارة إلى `equran.me` في ملف بيانات السور. يرجى الرجوع إلى `THIRD_PARTY_NOTICES.md` لمعلومات النسبة والمكونات الخارجية.

## الخصوصية والأمان

- لا ترفع قواعد بيانات SQLite الفعلية أو سجلات الطلاب وأولياء الأمور أو أرقام التواصل.
- لا ترفع كلمات المرور أو مفاتيح API أو ملفات الإعدادات الشخصية.
- استخدم بيانات تجريبية وهمية في الصور والأمثلة والاختبارات.
- راجع `SECURITY.md` قبل الإبلاغ عن مشكلة أمنية أو إعداد إصدار.

## الاختبارات والقيود الحالية

- لا تتضمن هذه النسخة حالياً مجموعة اختبارات آلية.
- يجب اختبار التطبيق بعد تثبيت المتطلبات في بيئة نظيفة.
- يجب اختبار تصدير PDF بعد إضافة ملفات الخط.
- ينبغي اختبار عمليات إنشاء التقارير وتعديلها وحفظ البيانات قبل اعتماد إصدار إنتاجي.
