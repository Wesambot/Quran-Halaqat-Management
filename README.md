نظام إدارة الحلقات القرآنية

تطبيق مكتبي باللغة العربية لإدارة حلقات تحفيظ القرآن الكريم، مبني باستخدام Python وFlet وقاعدة بيانات SQLite.

«حالة المشروع: مستودع عام مفتوح المصدر. هذه نسخة أولية منشورة، وقد اختُبرت عملية تشغيلها يدوياً من صاحب المشروع. لا يعني ذلك أن جميع الوظائف اجتازت اختبارات آلية.»

المزايا

- إدارة بيانات المعلم والحلقات والطلاب.
- تسجيل الحضور: حاضر، غائب، متأخر، ومستأذن.
- تسجيل الحفظ والمراجعة من سورة وآية إلى سورة وآية.
- تسجيل عدد الصفحات يدوياً عند التسميع.
- تقارير يومية وأسبوعية وشهرية وسنوية وفق الوظائف الموجودة في التطبيق.
- تصدير التقارير إلى PDF باستخدام الخط العربي.
- ملفات الطلاب والإنجازات والإعدادات والإحصائيات.

المتطلبات

- Python 3.12 (موصى به)
- Flet 0.24.1
- fpdf2
- arabic-reshaper
- python-bidi

التثبيت والتشغيل

python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate

python -m pip install -r requirements.txt
python main.py

الخط العربي وتصدير PDF

ملفات خط Amiri مضمنة بالفعل في المستودع داخل "assets/fonts/":

- "Amiri-Regular.ttf"
- "Amiri-Bold.ttf"
- "Amiri-Italic.ttf"
- "Amiri-BoldItalic.ttf"
- "OFL.txt" — نص ترخيص الخط.

يستخدم التطبيق ملفات الخط الموجودة في هذا المسار لتنسيق النص العربي في ملفات PDF. خط Amiri مرخص بموجب SIL Open Font License؛ راجع ملف "assets/fonts/OFL.txt" وشروط الخط قبل إعادة توزيعه ضمن حزمة أخرى.

بيانات القرآن الكريم

يحتوي "utils/quran_data.py" على بيانات وصفية للسور وأعداد الآيات وصفحات مصحف المدينة وبدايات الأجزاء والأحزاب. ويحتوي "utils/hizb_boundaries.py" على نقاط بداية الأحزاب الستين. راجع "THIRD_PARTY_NOTICES.md" لمعلومات المصادر والنسبة والمكونات الخارجية.

الخصوصية والأمان

- لا ترفع قواعد بيانات SQLite الفعلية أو سجلات الطلاب وأولياء الأمور أو أرقام التواصل.
- لا ترفع كلمات المرور أو مفاتيح API أو ملفات الإعدادات الشخصية.
- استخدم بيانات تجريبية وهمية في الصور والأمثلة والاختبارات.
- راجع "SECURITY.md" قبل الإبلاغ عن مشكلة أمنية.

الاختبارات والقيود الحالية

- توجد اختبارات آلية أساسية لمحرك الإحصائيات والتحقق من نطاقات الآيات وحدود الأحزاب والأجزاء.
- لتثبيت أدوات التطوير وتشغيل الاختبارات:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

- يجرى تشغيل الاختبارات تلقائياً عبر GitHub Actions عند الدفع إلى الفرع الرئيسي أو فتح طلب دمج.
- الاختبارات الآلية الحالية لا تغطي جميع واجهات التطبيق أو كل مسارات قاعدة البيانات والتقارير؛ لذلك اختبر التطبيق بعد تثبيت المتطلبات في بيئة نظيفة.
- اختبر تصدير PDF على جهازك وتأكد من ظهور الخط العربي بشكل صحيح.
- ينبغي اختبار إنشاء التقارير وتعديلها وحفظ البيانات قبل اعتماد إصدار إنتاجي.
